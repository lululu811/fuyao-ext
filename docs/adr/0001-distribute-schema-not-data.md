# 不分发任何数据，只分发数据契约

---
status: accepted
date: 2026-10-02
---

本项目**不发布任何 `.duckdb`、`parquet`、`csv` 或其他形式的市场数据**。只发布表结构、数据来源说明与计算代码，使用者自带数据源与 API key 自行建库。

上游是同花顺的付费金融数据服务（`fuyao.aicubes.cn`），本项目作者是该服务的**付费用户**而非版权所有方，无任何数据的再分发权。此外原始库中含自然人信息（基金前十大持有人姓名、基金经理姓名），即便数据权利清晰也不宜随仓库发布。

## Considered Options

- **发布完整数据文件** —— 权利不允许，且原始数据含自然人姓名，直接排除。
- **发布脱敏样本数据**（例如只保留 100 只票、只保留近一年） —— 曾认真考虑。技术上可行（抽样、截断、列裁剪），但"脱敏"在金融数据上极难做到可验证：抽样后的宽表仍可反推个股，且脱敏流程会成为持续的维护负担。排除。
- **只发 schema，采集与计算代码也不发** —— 最保守，但会退化成一堆无人能用的建表语句。排除。

## Consequences

- 仓库体积为 KB 级，不存在大文件 LFS、CI 拉取超时、克隆缓慢等问题。
- 使用者必须自备数据源与凭据。**这是本项目最大的采用门槛**，必须在 README 显著位置说明，并提供一个参考实现把门槛降到"填一个 API key"。
- 交付指标引擎的职责从"给你 10,349,853 行算好的结果"变成"给你一个能自己算出这 10,349,853 行的引擎"。项目价值从数据规模转移到工程与抽象设计上。
- 未来若上游开放数据再分发条款，本决策可重新评估。
