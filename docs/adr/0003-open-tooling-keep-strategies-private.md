# 工具层完全开源，策略层保留私有

---
status: accepted
date: 2026-10-02
---

数据契约、Ingestor 抽象、指标引擎（含全部 zettaranc 指标列）**完全开源**；选股与交易战法、胜率统计、仓位安排、B1 选股模型**保留在私有仓库**，不进入本项目。

## 划分依据

区分标准是"**被看见之后是否还成立**"：

| 内容 | 判断 |
|---|---|
| 264 列指标引擎 | 工程抽象，公开后价值不损失 |
| zettaranc 指标（6 列） | 公式极简（如四线几何倍增平均），藏不住；且公开反而证明了 config 驱动列展开可容纳库外私有指标，是能力证明 |
| 选股战法、胜率、盈亏比、仓位节奏 | **被看见之后即失效**。这才是真正的 alpha |

本项目作者的判断是：指标不是护城河，战法才是。因此公开全部指标、彻底保留战法，比在指标列上遮遮掩掩更诚实，也更符合"我开源的是工具层"这一叙事。

## Consequences

- `strategies/`、`b1.md` 及相关选股 SQL **不迁入本仓库**。若需在公开仓演示接口形态，只保留 1–2 个完全基于公开指标列编写的示例 SQL。
- README 必须显式声明策略层私有，不得让读者误以为仓库内容不完整。
- 私有仓中存在真实资金安排的具体数字（单笔仓位、分批节奏），比公开战法定义本身更敏感，迁移时需一并处理。
- 公开仓的指标列若被反用于选股，私有战法仍需依赖未公开的筛选顺序与资金管理规则 —— 这一点需在战法实现中确认，不假设"列不公开就安全"。
