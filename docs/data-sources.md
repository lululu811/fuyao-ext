# 数据来源说明

本文件说明 fuyao-ext 使用什么数据、数据从哪来、以及使用者需要自己准备什么。

---

## 1. 上游数据服务

**同花顺 hithink-finance**

- 官网：<https://fuyao.aicubes.cn/>
- API Key 申请：<https://fuyao.aicubes.cn/admin/>
- 本项目对接的接口：REST API（`X-api-key` 请求头鉴权）

> **本项目与同花顺（300033.SZ）无隶属、授权或合作关系。**
> 本项目是调用其公开 API 的第三方工具。所有数据版权归同花顺所有。
> 上游服务的可用性、接口稳定性、条款与价格均可能变化，本项目不对其作任何承诺。
> 需使用者自行阅读并接受上游的服务条款。

数据来源分两类（体现在导入批次的 `source` 字段）：

| 来源类型 | 说明 |
|---|---|
| `rest` | 调用上游 REST API 拉取 |
| `parquet` | 上游提供的批量发布包 |

## 2. 使用者需要自己准备什么

本项目**不提供任何数据**。要跑通完整链路，你需要：

1. 一个上游 API Key（或任意其他数据源，见第 5 节）
2. 自行建库、执行 Ingestor 灌数、运行指标引擎

### 核心契约的最小输入

指标引擎只依赖三样东西，其余全部可选：

| 需要 | 用途 | 缺失后果 |
|---|---|---|
| 证券标识（`thscode` 或可映射到它的标识） | 主键 | 无法运行 |
| 日线 OHLCV（开高低收、成交量、成交额） | 全部指标 | 无法计算 |
| 复权因子 | 前复权/后复权口径 | 指标跨除权日失真 |

> 若你的数据源使用 6 位代码而非同花顺标识，需先做映射。映射表由 Ingestor 负责，
> 不在契约内。

## 3. 数据域覆盖范围

7 个 DuckDB 数据域，77 张基表 + 41 个视图：

| 数据域 | 覆盖内容 | 是否属于核心契约 |
|---|---|---|
| `market` | 日线行情、复权因子、证券目录、除权除息事件 | ✅ 核心 |
| `financials` | 三大报表、财务指标、估值快照、交易日历 | 可选 |
| `index` | 指数行情、成分股、指数目录 | 可选 |
| `fund` | 公募基金净值、持仓、持有人结构、ETF 行情 | 可选 |
| `futures` | 期货日线/分时/基差/仓单/持仓 | 可选 |
| `special` | 集合竞价、涨停池、龙虎榜、异动、热度榜 | 可选 |
| `indicators` | 264 列指标宽表（**本项目计算产出**） | ✅ 本项目产物 |

完整表结构见 [`schema/`](../schema)，字段语义见 [`field-dictionary.md`](field-dictionary.md)。

### 关于基金数据中的个人信息

上游的基金数据包含自然人姓名（基金定期报告披露的前十大持有人、基金经理姓名）。
这属于上游的公开披露内容，但**本项目不随仓库分发任何数据**，因此该问题在本项目中不存在。
使用者若自行落库，需自行评估所在司法辖区的个人信息处理要求。

## 5. 换一个数据源

`Ingestor` 抽象的存在意义就是不被单一数据源绑定。实现一个你自己的 Ingestor，
只要能产出第 2 节的三样核心输入即可。

（候选：tushare / akshare，待定）。

## 6. 明确不包含的东西

| 不包含 | 原因 |
|---|---|
| 任何 `.duckdb` / `.parquet` / `.csv` 数据文件 | 无再分发权（[ADR-0001](../docs/adr/0001-distribute-schema-not-data.md)） |
| 上游客户端仓库的代码 | 非本项目所有（[ADR-0002](../docs/adr/0002-exclude-hithink-financial-api.md)） |
| 选股策略、胜率、仓位安排 | 策略层私有（[ADR-0003](../docs/adr/0003-open-tooling-keep-strategies-private.md)） |
| TA-Lib / pandas-ta 的代码副本 | 第三方 MIT 库，作为依赖声明 |
